## 判讀原則

「已驗證」限於指定環境、筆記本與觀察樣本；模擬通過不代表真人通過。設計規則、程式實作與觀察結果分欄記錄，不以總測試數相加宣稱完成率。

## 異常與不確定性

- 最新照護觀察窗出現 3 次忙碌期間 `/tick` 429；其後 tick 與清除完成。時間相符於容量壓力，但 HTTP 狀態本身不是根因證明。
- 另有一次唯讀檢查上游 503，重讀成功並確認目標、49 來源及歷史 0；這不構成全面恢復能力保證。
- 刻意未授權檢查的 403 與正常服務錯誤分開，不把它列為合法使用者請求失敗。
- 現有引用紀錄不足以判定是上游解析、來源 ID 配對或摘錄正規化哪一階段失敗，不能先指定根因。
- 21 項雲端模擬發生在 Cloud Tasks 加入前，完整 Cloud Tasks 故障重試／去重驗證尚無對應結論。
- 重新部署、實例中斷、租約接管、跨機時鐘偏差、人工復原及紀錄保留仍待完整驗證。

## 7A2 邊界核對

本 MVP 使用獨立測試環境；文件整理不更動服務、不新增查詢、不刪聊天。既有 7A2 程式、部署、Repo、來源及分享均為不可修改邊界。本 Repo 借用文件分類，不借用原專案驗收。
