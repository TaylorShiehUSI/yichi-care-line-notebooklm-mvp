# 個人與群組使用說明

此為受控技術 MVP 的操作說明；Bot 加入資訊由管理者另行提供。本 Repo 不公開測試帳號、識別碼或部署入口。

## 個人聊天室

1. 加入管理者提供的測試 Bot，輸入「排隊」。
2. 若有其他人使用，閱讀等待通知；等待期間的原問題不保留。
3. 收到「輪到您了」後重新發送問題。可先問：「請依筆記本來源，整理家庭照顧者可先了解的三個照護主題；來源不足請明說。」
4. 答案回來後，可在同一輪問：「請把剛才第二點說得更白話。」這是操作示例，並非宣稱照護語料追問已驗證。
5. 輸入「結束」提早離開；收到清除中通知後等待完成，需要再用時重新排隊。

## 群組聊天室

1. 由管理者安排將 Bot 加入測試群組。
2. 使用 LINE 的真正提及功能選取 Bot，再輸入「排隊」。只打出文字 `@Bot` 不一定構成有效提及。
3. 輪到時，每一題或指令仍先真正 @Bot。
4. 只有獲得該席位的使用者可續問；其他成員另行排隊。
5. 每次 @Bot 後輸入「結束」離開；答案與通知回到原群組。

## 等待與時間規則

| 情況 | 說明 |
|---|---|
| 一人使用、多入口等待 | 共用單一席位；不同入口不會同時查詢 NotebookLM |
| 前方 0 位等待者 | 不代表沒有使用中的持有者；可能是自己為下一位 |
| 輪到後未提問 | 邀請可到期，須重新加入 |
| 開始使用 | 第一題接受後最多 10 分鐘；距最後接受問題 2 分鐘無新題即回收 |
| 問題仍處理中 | 等待本題結果；不要反覆重送，以免造成操作混淆 |
| 清除中／暫停 | 不直接交接；由管理者核對異常，沒有承諾立即恢復 |

回收由定期檢查執行，可能延後；2 分鐘從最後接受問題起算，不是答案送達起算。

## 測試時請注意

群組答案對全群公開，測試請用一般性問題，避免姓名、病歷或可辨認家人的細節。答案基於筆記本資訊，技術測試不等於專業照護判斷。最新照護測試的引用尚未核對成功，不能把數字標記當成來源已確認。

建議回報：個人／群組入口、操作步驟、時間、看到的通知、預期與實際差異。公開文件不附原始聊天或他人識別資料。
