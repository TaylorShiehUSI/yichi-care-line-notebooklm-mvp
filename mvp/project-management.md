# 專案管理與保護邊界

文件整理版 v0.1；快照：2026-11-18。

## 目標與交付

以獨立 Repo 保存 LINE × NotebookLM MVP 文件，先私有整理，再經使用者於 2026-11-18 同意公開，供期末報告與成果交流使用。文件可追溯需求、決策及驗證，並清楚區分已完成、部分驗證與未驗證。MVP 功能維持凍結。

## 分工

| 角色 | 責任 | 不能代替的證據 |
|---|---|---|
| 使用者 | 提出需求、決定範圍與授權、登入操作、真人 LINE 測試、決定公開 | 同一人測試不能當成不同真人測試 |
| Codex | 實作、記錄、對照程式與輸出、雲端及通知核對、整理文件 | 紀錄成功不能當作醫療內容正確或所有使用者已讀 |
| Claude | 原規劃對話的設計討論、方案比較、依摘要檢查過度宣稱 | 摘要複核不是完整 code review，也不是獨立測試 |

## 隔離與資料原則

**最高前提：不得動到任何 7A2 成果。** 使用獨立測試 Bot、GAS、雲端環境與專用 NotebookLM 帳號；文件 Repo 不修改任何運行服務。

筆記本來源、分享與設定不因測試改動；切換時測試帳號已存在的 1 則聊天，在停止並取得使用者另行明確同意後才清除。後續當輪清除只限可識別的專用測試聊天，遇到未知歷史先停止。

本 Repo 不含憑證、Cookie、原始 LINE 身分／聊天室識別碼、實際部署入口、來源全文、原始聊天與測試 ZIP。證據以代號及去識別摘要呈現。原始證據另行保管，不因 Repo 私有就擴大收錄。

## 風險與限制

| 風險／未知 | 本版處理 |
|---|---|
| 非官方 NotebookLM web 介面／登入失效 | 明示依賴；長期穩定性未驗 |
| 共用帳號串話 | 單席位、清除核對、未知暫停；Koopman 標記控制僅屬有限樣本 |
| 照護引用核對失敗 | 記錄 false，不以數字標記當作來源已驗 |
| 群組公開及不同人上下文 | 身分加聊天室情境；操作說明揭露群組可見 |
| 排程與容量壓力 | 說明每分鐘 tick 與已見 429／503，不宣稱秒級或高可用 |
| 費用、配額、長期維護 | 沒有宣稱免費、固定月費或完成成本模型 |
| 正式用途所需安全、授權及營運程序 | 待確認；摘要未提供證據不等於措施不存在或未經同意 |

## 期末報告建議敘事

以「需求 → 最不確定假設 → 小測試 → 發現限制 → 設計取捨 → 真人資訊流 → 尚待驗證」呈現。亮點是把限制轉成可實作的服務規則，並以證據控制結論；不承諾名次或誇大容量。
